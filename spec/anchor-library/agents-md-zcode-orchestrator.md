   - **派发去重租约（编排器级硬约束，派发前置门，父会话不可豁免）**：父会话派发任何复审子代理（`plan-reviewer-subagent-sp` / `pr-reviewer-subagent-sp`）前必须履行本协议，未履行或租约未取得即派发即属违反本节：① 以宿主目录枚举核查产物存放面（`.kilo/plans/` 全目录，含 `review/`、`pr-review/` 子目录——租约文件落 plans 根，检查范围必须覆盖之）——同目标（同 HEAD + 同报告路径主题）的活跃租约在场即判"疑似同题并发"；**活跃租约形态＝`.kilo/plans/*.lease.md` 且首行以 `LEASE:` 开头**（单行格式 `LEASE: <目标>|<角色>|<ISO时间>|<会话标识>`），首行 `RELEASED:` 开头视为已释放、不计入活跃并发。另：30 分钟内同 HEAD 同主题新产物在场时，同样判"疑似同题并发"，暂停派发并呈报人类（两个会话对同一请求重复派发会共用受控通道，造成跨会话命令逐字重合拦截与回执串扰，双方证据链互相污染）；② 确认无并发后方可取得租约——父会话经 `task` 指令 `plan-writer-subagent-sp` 以其受控写通道 `write_scoped_file`（`.kilo/plans/<标识>.lease.md` 属该工具 `.kilo/plans/` 下 `.md` 路径锁放行面）在派发同轮落租约，并令该子代理写后立即回读核验首行（逐字比对整行四字段，而非仅比前缀）：若首行的会话标识不是本会话（检查与落盘之间被他方抢先），判租约未取得，立即停止派发并呈报人类——宿主写工具无独占创建原语，写后逐字回读只能检出"回读之前"的他方覆盖，不能证明排他性、也无法发现"回读之后"的覆盖：本协议仅以此取得语义实现"让位而非覆写"，并非排他保证；**派发放行条件按"写面取得语义是否排他"两级可判定**：(a) 若部署环境的写面取得动作实际运行于原子排他取得之上（如同目录 O_EXCL 锁文件互斥——服务端受控写工具的锁形态，或宿主 O_EXCL 创建原语），且本次租约取得确实经该排他通道完成，则允许派发；(b) 若写面取得语义不排他，派发前必须履行"让位而非覆写 + 写后逐字回读 + 会话标识失配即停机报人"全链，并由派发方（父会话）对租约首行完成独立 Read 复核后方可派发；禁止以"环境理论上有能力"作为放行依据——放行判定只看本次取得实际采用的取得语义；会话标识必须为本会话专属且含当次生成的随机或时间熵，严禁复用固定字面量；唯一标识降低静默覆写风险（会话标识相异时回读可检出"回读之前"的被抢先写入），但回读之后发生的覆盖仍不可由回读发现；父会话收到子代理回报后**必须自行以宿主读取工具 Read 该租约文件复核首行会话标识**，复核不符视同未取得、立即停机报人；③ 释放＝产物落盘并回读核验通过后，派发方（zcode 父会话无原生写通道）经同一 `task` 指令 `plan-writer-subagent-sp` 以 `write_scoped_file` 整文件重写租约内容实现改写——租约仅单行时即重写该行、把行首 `LEASE:` 改为 `RELEASED:`，文件名与其余字段逐字不动（以改写代替删除，兼容无删除通道宿主）；活跃判定：检查方仅认首行以 `LEASE:` 开头的租约，首行 `RELEASED:` 开头视为已释放、不计入活跃并发；④ 遗留的活跃租约（所属会话崩溃或中断、未走到释放步）不由机器自行判陈旧清理：暂停派发呈报人类时，必须随呈报列出该租约路径、所属会话标识与首行 ISO 时间戳（时间戳字段仅供人类裁决参考），经人类确认所属会话已终止并清理该租约后，同题方可重派；若该租约首行已损坏（不满足以 `|` 分隔的四段正式格式，无法机械提取目标/角色/时间/会话标识），同样暂停派发并原样上报首行内容交人类裁决，机器不得自行重写或清空。**残留竞态如实声明**：检查与落盘两动作之间仍存窄窗（两会话可同时通过"无租约"检查），本协议以"写后逐字回读 + 唯一标识 + 父会话独立复核 + 标识不符即让位停机报人"把窗口收窄至"覆盖写晚于对方回读"的极端交错，并以检查侧常驻闸（registry CLAUSE `lease-exclusive-readback` / `lease-identity-entropy`，`checks/run.mjs` 全量扫描）与受控通道重复命令拦截作二级兜底；平台写工具无 O_EXCL 原语，真原子独占创建不可达；
