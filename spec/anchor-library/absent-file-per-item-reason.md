   - **缺席文件论证（缺口不可静默）**：凡在探索取证中出现真实 `路径:行号`、或与 Files 表同目录同职责的邻近文件，而未被列入本计划 Files 表的，必须在「明确不纳入的事项」节逐条列出并各给一行缺席理由；无理由者视为漏列，属计划完整性缺陷，其等级按被遗漏文件的实际影响裁定（四要素判据：遗漏是否可达、影响哪些下游消费点、可逆性、触发概率证据），不按"漏列"类别自动判 Critical。**严禁把「明确不纳入的事项」当作一次性打包排除未经逐条论证文件的场所。**
