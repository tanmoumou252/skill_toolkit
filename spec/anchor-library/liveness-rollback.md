8. 【异常路径回滚与持锁活性】：① 对本次改动涉及的**每个** try / catch（或等价错误分支）块，列出成功路径写过的**全部**副作用（文件、缓存、持久化键、临时状态、消息、锁、游标），逐项核对 except / 早退 / 超时 / 重试分支是否撤销**同一批**副作用；「成功清 X、失败不清 X」按四要素判据定级（不可逆且无恢复路径者判 Critical，可由重算/备份恢复者按实际影响定级）。② 对每个持锁区间，枚举区间内发生的全部外部操作（无超时 join / 进程等待 / 网络 / 文件 IO / 再次取锁 / 消息投递）；其中存在可能无界阻塞者，须给出可构造该阻塞的触发输入并评估四要素（阻塞的可达条件、影响范围、有无超时兜底即恢复方式、触发概率证据），仅当无超时兜底且阻塞可达时判 Critical 活性缺陷——happy path 全绿不构成抗辩，「测试未复现挂死」同样不构成抗辩，按本节以嫌疑未排除处理。
