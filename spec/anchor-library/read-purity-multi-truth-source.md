7. 【读纯度与多真相源】：① 命名语义为读（`get_` / `fetch` / `query` / `list` / `read` / `peek` / `status` / `describe`）的路径若写入共享状态、缓存、单例或模块级变量，先确认读契约违反及其可观察影响（哪些下游消费点在旧契约下的解读被改变、影响是否可逆），再按四要素判据定级（影响不可逆且可达者判 Critical，影响可逆或有冗余恢复路径者按实际影响定级），并逐条列出被污染的下游消费点及其在旧契约下的解读；② 同一语义（如"是否运行""是否完成""是否已同步"）若在两处及以上独立存储、靠手工赋值对齐而无单一权威源，先核实是否已产生可观察的行为分叉（任一处漏写时另一处如何响应），无分叉证据的按 Important 要求收敛到单一权威源，分叉确凿且不可逆的判 Critical。
