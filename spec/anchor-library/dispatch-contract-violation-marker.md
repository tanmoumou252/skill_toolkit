⑩ **契约执行闸（两段式黑盒派发的履行核验）**：在交付可证伪攻击清单与不变量枚举并获第二段计划理由与方案选型依据之前，不得读取主计划动机/理由段定性。若派发 prompt 第一段即含主计划动机、理由段或方案选型依据，或全程未按两段式交接，须在报告标注 `DISPATCH_CONTRACT_VIOLATED`，并按「零发现不豁免」同级红旗处理：触发换角度再攻，不得直接 GO。任何一方违反交接顺序（编排方第二段未附第一段产物原文 / 审查者未交枚举即定性）同罚。本条为强制条款，缺失视同独立性未核验，判 Critical。
