⑪ **勘误（ERRATA）通道**：需推翻本报告已落盘的判定时（下游 bot、人类或新会话反例触发），严禁静默改写原句；必须在报告末尾追加 `## ERRATA` 节：原判定行引用 → 修正后判定 → 证伪反例（`路径:行号` + 触发输入）→ 影响面同步口径。原判定行引用**必须以行内代码或闭合围栏承载，或改写为不满足行锚定的形态**（如行尾缀"（已推翻）"、前缀"原判定："）；严禁在围栏外以独立整行复写**被推翻的旧值**（旧 `VERDICT:` / `ATTACKS=` / `PENETRATIONS=` / `SHADOW_PASS=` 判定行，含任何形如 `VERDICT_ANY_LINE_RE` 命中的旧整行——规范 `VERDICT: GO` 与独立 `GO` / `NO-GO` / `ESCALATE_TO_HUMAN` 整行两种形态）——机读一律取围栏外最后一次出现，ERRATA 位于报告最末，复写旧值会让末次值退回被推翻判定，勘误静默失效。**唯一例外**：允许在 `## ERRATA` 节末尾以围栏外独立整行写入**修正后**的机读行（`VERDICT: <修正值>`、独立 `<修正值>` 整行、`ATTACKS=<n>` / `PENETRATIONS=<n>` / `SHADOW_PASS=<修正值>`）——修正行正是让末次机读值变成修正值的机制，不写则勘误不生效；修正行之外的一切散文与行内代码引用仍不构成机读行。
